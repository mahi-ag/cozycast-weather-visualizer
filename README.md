**CozyCast — Atmospheric Weather-to-Textile Visualizer**  
*React.js | TypeScript | HTML5 Canvas | CSS | REST APIs*

- Developed and deployed an interactive weather visualization application integrating Open-Meteo APIs for location search and historical temperature data.
- Engineered a Canvas-based atmospheric rendering system with weather-responsive rain, snow, cloud, and lighting effects.
- Built a responsive, iOS-inspired interface featuring customizable textile visualizations, persistent preferences, and SVG/CSV exports.

**Live Demo:** https://cozycast-weather-visualizer.vercel.app/
